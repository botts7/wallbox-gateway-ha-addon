What happens during OTA

  1. Add-on reads the file and computes its MD5 locally.
  2. Add-on POSTs the file to the gateway's /api/ota as multipart with X-Firmware-MD5 header.
  3. Gateway validates the ESP32 magic byte, pauses BLE for 5 minutes, and writes to the OTA partition while verifying the MD5 streaming.
  4. Gateway responds 200 OK, then reboots ~2 s later into the new firmware. The dashboard becomes unreachable for ~30 s.
  5. Add-on history records the attempt either way (success or rejection) so you can see what happened.
